# 上岸刷题 · 每日资料分析

基于《26行测5000-资料分析》的本地刷题网站。题库共 203 篇材料、1015 道题；题目预先排成固定且不重复的顺序，从 2026 年 9 月 9 日起每天安排 2 篇完整材料（10 题）。

## 运行

在本目录打开终端：

```powershell
python -m http.server 8765
```

然后访问 <http://localhost:8765>。不要直接双击 `index.html`，否则浏览器可能限制内嵌 PDF。

## 数据处理方式

- Windows 中文 OCR 只在后台识别裁剪边界，不在网页中展示 OCR 文字。
- 每组只显示该篇材料、对应 5 道题、完整选项以及必要的图表和表格裁图。
- 已去掉整本 PDF 阅读器、前后相邻题组、页码和多余页边距。
- 答案由书内第 302-305 页“答案速览”按版面坐标识别并与 203 篇材料逐一映射。
- 作答记录、正确率、连续天数和错题本保存在浏览器 `localStorage` 中。

## 不重复规则

- 每个日期对应固定的两篇材料，刷新或改变日期打开顺序都不会变化。
- 题目按预先排好的顺序逐日出现，不会每天重新随机。
- 203 篇材料全部刷完前不会重复；最后一天剩 1 篇时只出 5 题。
- 清除浏览器站点数据会清除作答记录。

## 计时器与题库接口

- 点击“开始答题”后自动开始计时并显示题目；提交完当天两组题后自动停止计时。
- 当天用时保存在浏览器答题记录中，也会包含在导出的 JSON 备份里。
- 错题复盘按日期分组展示；每篇材料先保留资料与图表，再按错题题号显示原题裁图和独立解析框。复杂版式使用完整原题兜底，避免误裁。解析内容保存在本机，并随 JSON 备份导出和恢复。
- “邮箱提醒”会打开默认邮件客户端并预填做题提醒和网站链接。
- 左侧日历只允许打开 2026 年 9 月 9 日至今天的日期；往日未做题目可以补做，未来题目不会在界面中显示。
- `config.js` 中的 `pdfImportEndpoint` 是未来 PDF 题库处理服务地址；留空时网站仍正常使用内置题库。
- 导入接口使用 `POST multipart/form-data`，PDF 文件字段名为 `file`。
- 接口返回 JSON：`{ "manifest": {...}, "cards": {...} }`。`manifest.groups` 中每组须有 5 个答案，`cards.cards` 中对应题组须提供 `fullVisuals` 图片 URL 数组。
- 导入成功后，题库定义保存在浏览器中；题面图片由处理服务或静态资源地址提供。点击“恢复内置题库”可随时切回当前上册题库。
- GitHub Pages 本身不能执行 PDF 切题，处理接口需要另行部署，并允许网站域名跨域访问。
